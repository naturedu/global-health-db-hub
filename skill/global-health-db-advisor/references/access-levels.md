# 数据开放度分级与申请流程（5 级）

> 判断"这个库能不能拿到数据、怎么拿、多久、多少钱"的统一标准。
> 金额与周期会随机构政策调整，引用具体数字时须注明"以官网当期说明为准"。

---

## ★ 一级：完全公开（Open Access）

**特征**：无申请、无审批、无需注册，浏览器直接下载或通过 API/R/Python 包取数。

**典型库**
- NHANES（美国国家健康与营养调查）
- GEO（基因表达综合数据库）
- GBD / IHME 结果数据库
- World Bank / WHO GHO
- AIHW（澳大利亚健康与福利研究院数据表）
- GDC / TCGA、SRA、ArrayExpress、Dryad、Zenodo

**变量可得性**：变量级与个体级记录基本都可下载。

**注意事项**
- 许可各异：CC0、CC-BY、自定义条款。商用与非商用限制要看清。
- **SEER 不属于本级**：公开的是汇总统计（Cancer Stat Facts / SEER*Stat 会话）；个案数据要提交研究摘要并签 RDA，属 ★★★。
- GEO 中带受控访问标记的 series（如 dbGaP-linked）、SEER 的基因数据不在本级。
- 发表时仍须引用数据来源，且不能声称"数据由作者收集"。

**建议路径**：先查 codebook / Data Dictionary 确认变量名与年份 → 下载 SAS transport / CSV → 用调查设计变量（如 NHANES 的 SDMVPSU、SDMVSTRA、WTMEC2YR）做加权。

---

## ★★ 二级：注册后下载（Registration）

**特征**：免费，需注册账号、填写真实身份与用途说明，部分需机构邮箱；下载即用。

**典型库**
- CHARLS（中国健康与养老追踪调查）
- CHNS、CLHLS、CFPS
- PBICR（中国居民心理与健康调查）
- HILDA（澳大利亚，需注册）
- 45 and Up Study（数据字典公开，个体数据需申请，介于 ★★–★★★）
- ALSWH、Ten to Men（部分公开报告 + 申请数据）

**变量可得性**：变量级数据可下载；敏感变量（精确地理、基因、精确日期）需额外协议。

**流程（典型 1–7 天）**
1. 官网注册账号（机构邮箱更快通过）
2. 填写研究用途 / 项目名称 / 简要研究问题
3. 同意数据使用条款（不得再分发、不得再识别）
4. 下载数据 + codebook + 问卷

**常见坑**
- 中国队列平台多为**中文注册页**，机构名称需与公章一致。
- 同一库不同"wave/年份"是独立数据集，跨年合并要核对变量编码是否变化（如 CHARLS 血压测量在 2011/2015 有差异）。
- 下载的 ID 是脱敏 ID，不要与外部名单做链接。

---

## ★★★ 三级：培训 + 数据使用协议（DUA）

**特征**：免费或低费，但必须先完成人类受试者保护培训（CITI Program 等）、签署 DUA，获批后在受控环境或授权账号内使用。

**典型库**
- UK Biobank（£3,000–9,000 量级申请费，随项目规模浮动）
- MIMIC-IV / MIMIC-CXR（需 CITI 培训 + PhysioNet 认证）
- All of Us Research Program（需 Researcher Workbench 认证）
- eICU-CRD、PIC 数据库（部分）
- SEER 美国肿瘤登记（个案数据：提交研究摘要 + 签 RDA，免费）

**变量可得性**：可拿到变量级数据，但**按获批字段范围**提供；影像/组学原始文件常需额外申请。

**流程（典型 2–6 周，UKB 4–8 周）**
1. 完成 CITI "Data or Specimens Only Research" 模块，拿到证书编号
2. 在平台建项目，填研究摘要、所需字段/表、分析计划
3. 机构签署 DUA（需单位法人/科研管理部门盖章，个人签无效）
4. 平台审核（MIMIC 为自动+人工，UKB 为 Access Management Team 评审）
5. 缴费（UKB）→ 获得数据访问权限（UKB 走 AMS 云端，不出境原始基因型）

**常见坑**
- **DUA 是机构对机构**，学生个人无法单独申请；必须找导师/单位科研处。
- UKB 的"申请号（Application Number）"是论文致谢的必备字段，务必记下。
- MIMIC 数据不得再分发，包括不得上传到公开仓库；代码可以开源，数据不行。
- 获批字段外的变量即使在同一张表里也不能用，扩展字段要提 amendment。

---

## ★★★★ 四级：正式申请 + 付费（Controlled Access）

**特征**：需提交完整研究计划、机构审批、伦理证明，部分需付费；由 Data Access Committee（DAC）评审；数据在受控环境内分析，不落地。

**典型库**
- dbGaP（NCBI，受控访问层级）
- 部分国家医保/商保理赔数据（如澳大利亚 Services Australia / MBS-PBS 数据、部分省医保局数据）
- 香港医院管理局（HA）数据（需 HA 伦理与数据管理部门批准，常要求本地合作）
- 部分肿瘤登记细节数据

**变量可得性**：**部分可得**——按获批的研究问题与字段清单提供；原始测序/影像文件常需单独的数据共享协议。

**流程（典型 1–6 个月）**
1. 在 dbGaP 找到 study，读 Data Use Certification（DUC）
2. 由**机构签署官（Signing Official）**提交请求，附研究用途说明（Research Use Statement）
3. DAC 月度/季度评审
4. 批准后通过 SRA Toolkit / cloud 授权访问；分析在受控环境（如 AnVIL、SBGrid）
5. 结果导出需经过审核（防泄漏个体信息）

**常见坑**
- 中国研究者申请 dbGaP 涉及**数据出境与人类遗传资源**问题，需本单位伦理与科技处前置确认，部分 study 明确限制特定国家申请者。
- 医保理赔数据变量名与临床语义差异大，先要数据字典再设计研究。
- "付费"常按数据量/字段数/年数计价，预算要提前问。

---

## ★★★★★ 五级：必须本地合作（Collaboration Only）

**特征**：不开放下载、不接受公开申请，只能与数据持有团队建立合作关系，签合作协议，通常涉及**共同作者署名**、成果共享、甚至数据不出境。

**典型情形**
- 中国大型人群队列的**原始个体数据**（多数只放行汇总结果或派生变量）
- 医院院内数据（HIS/EMR/影像 PACS）
- 香港医管局临床数据
- 中国肿瘤登记（NCCR）个体级个案数据
- 企业/保险 proprietary 数据

**变量可得性**：**通常不可**。可谈的是"由持有方在你的分析计划下跑模型，返回结果"。

**流程（半年起）**
1. 通过官网/通讯作者联系数据持有团队，提交 1–2 页研究意向书
2. 双方 PI 沟通，确定可行性、变量范围、署名与知识产权
3. 签署合作协议 + 伦理审批（双方 IRB）
4. 派研究者驻场或远程受控环境分析
5. 论文共同署名，投稿前经数据方审阅

**红线**
- 这类数据**法律上不可能**由网站/Skill 抓取。任何声称"能拉原始记录"的工具都是违规的。
- 平台能做的是：变量字典（元数据）+ 联系人/申请路由 + 合作范式模板。

## 一张速查表

| 想做的事 | 级别 | 现实预期 |
|---|---|---|
| 快速发一篇横断面/生态学论文 | ★ / ★★ | 1 周内拿到数据，可行 |
| 做基因-环境交互、影像组学 | ★★★ / ★★★★ | 1–6 个月，需导师与单位背书 |
| 用院内 EMR 做预测模型并外部验证 | ★★★（MIMIC）→ ★★★★★（本院） | 先用 MIMIC 做方法学，再用合作数据验证 |
| 拿到中国队列原始个体数据 | ★★★★★ | 基本只能合作，做好共同署名准备 |
| 商业/政策报告用汇总指标 | ★ | 直接下载，注明来源 |
